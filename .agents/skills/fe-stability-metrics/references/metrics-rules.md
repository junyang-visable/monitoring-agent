# 指标计算与判定规则

## 日均归一化

```
基线/天 = BASE 总量 / BASE_DAYS
当前/天 = CURR 总量 / CURR_DAYS
变化%   = (当前/天 - 基线/天) / 基线/天 × 100%
```

基线为 0 时：变化% 记为 `null`，趋势记为 `→ 无法对比`，报告中注明「基线无数据」。

## 趋势箭头

| 变化幅度 | 标签 |
|---------|------|
| 正增长 ≥ 100% | `↑ 严重恶化` |
| 正增长 20%~99% | `↑ 恶化` |
| 正增长 5%~19% | `↑ 轻微上升` |
| ±5% 以内 | `→ 持平` |
| 负增长 -5%~-19% | `↓ 轻微下降` |
| 负增长 -20%~-49% | `↓ 改善` |
| 负增长 ≤ -50% | `↓ 显著改善` |

## 标题后缀

| 变化幅度 | 后缀 |
|---------|------|
| ≥ 100% | 严重恶化 |
| 50%~99% | 显著恶化 |
| 20%~49% | 恶化 / 上升 |
| -20%~20% | 基本持平 |
| -49%~-20% | 改善 |
| ≤ -50% | 显著改善 |

## 治理优先级

| 优先级 | 条件 |
|--------|------|
| **P0** | 日均 > 1000 且恶化 > 50%，或直接影响用户核心流程 |
| **P1** | 日均 > 100 且恶化 > 20%，或修复成本低 |
| **P2** | 日均 < 100 或趋势持平/改善，但需持续观察 |

## 指标键格式

统一使用 `{event_type}:{error_type}`，例如 `script_error:resource_load_failed`。不单独出现 error_type。
